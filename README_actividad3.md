# Actividad 3 — Taller EDA: Hábitos de pantalla antes de dormir y deuda de sueño

Análisis exploratorio de datos (EDA) sobre la relación entre el uso del celular antes de dormir y la
calidad del sueño, usando **Pandas**, **NumPy** y **Matplotlib**.

## Contenido
- `taller3_eda_sleep.ipynb`: notebook con el desarrollo completo del taller (exploración, limpieza,
  filtrado, transformación de variables, agrupaciones, 5 preguntas de análisis con gráficas y
  conclusiones).
- `bedtime_screentime_sleep_debt.csv`: dataset original usado como entrada.

## Dataset
Bedtime Screentime & Sleep Debt — Kaggle
https://www.kaggle.com/datasets

## Cómo ejecutar
```bash
pip install pandas numpy matplotlib jupyter
jupyter notebook taller3_eda_sleep.ipynb
```
